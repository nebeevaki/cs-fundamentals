# CS Fundamentals

Мои реализации алгоритмов и структур данных для изучения Computer Science
и подготовки к техническим собеседованиям.

Цель репозитория — не просто хранить готовые реализации, а разбирать:
- идею алгоритма;
- инварианты;
- временную и пространственную сложность;
- граничные случаи;
- тестирование.
