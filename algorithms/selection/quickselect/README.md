# Quickselect

Реализация алгоритма поиска **k-го минимального** и **k-го максимального** элемента без полной сортировки массива.

## Идея

Quickselect использует `partition`, как и Quick Sort:

```text
[ < pivot | == pivot | > pivot ]
```

После разбиения алгоритм продолжает работу только с той частью массива, в которой находится нужная порядковая статистика.

В реализации используется случайный `pivot` и three-way partition с тремя указателями: `equal`, `greater`, `current`.

## Использование

```python
from quick_select import kth_smallest, kth_largest

nums = [7, 2, 9, 1, 5, 3]

kth_smallest(nums, 3)  # 3
kth_largest(nums, 2)   # 7
```

`k` нумеруется с **1**. Повторяющиеся элементы учитываются.

> Алгоритм изменяет порядок элементов исходного списка, так как `partition` работает in-place.

## Сложность

- ожидаемое время: `O(n)`
- худший случай: `O(n²)`
- дополнительная память: `O(1)`

## Тесты

```bash
uv run pytest algorithms/selection/quickselect/test_quickselect.py -v
```

Тесты проверяют обычные случаи, дубликаты, отрицательные числа, некорректные значения `k` и случайные массивы.
