# Heap

Реализация бинарной **min-heap** на основе обычного Python-списка.

В min-heap каждый родительский элемент меньше или равен своим детям, поэтому минимальный элемент всегда находится в корне кучи — по индексу `0`.

## Как хранится куча

Куча представляет собой полное бинарное дерево, но отдельные объекты для узлов не нужны.

Все элементы хранятся в обычном списке:

```text
        1
      /   \
     3     2
    / \   /
   7   5  4
```

Такое дерево можно представить списком:

```python
[1, 3, 2, 7, 5, 4]
```

Для элемента с индексом `i`:

```python
parent = (i - 1) // 2
left = i * 2 + 1
right = i * 2 + 2
```

## Основные операции

Реализация содержит основные операции min-heap:

```python
add()
pop()
peak()
```

Также реализованы:

```python
len()
str()
```

## Добавление элемента

Метод `add` сначала добавляет новый элемент в конец списка.

После этого выполняется **просеивание вверх**.

Пока новый элемент меньше своего родителя, они меняются местами:

```text
добавление в конец
        ↓
сравнение с родителем
        ↓
обмен при необходимости
        ↓
переход выше
```

Просеивание заканчивается, когда:

- элемент дошёл до корня;
- родитель уже меньше или равен текущему элементу.

## Удаление минимального элемента

Метод `pop` возвращает минимальный элемент кучи.

Так как минимум всегда находится в корне:

```python
self.lst[0]
```

сначала он сохраняется для будущего возврата.

После этого последний элемент списка переносится в корень, а затем выполняется **просеивание вниз**.

На каждом шаге:

1. Находим левого и правого ребёнка.
2. Выбираем меньшего из существующих детей.
3. Если текущий элемент больше меньшего ребёнка — меняем их местами.
4. Продолжаем движение вниз.

Просеивание заканчивается, когда текущий элемент меньше или равен обоим детям либо когда детей больше нет.

Отдельно обрабатываются случаи:

- пустой кучи;
- кучи из одного элемента;
- вершины только с левым ребёнком.

## Получение минимального элемента

Метод `peak` возвращает минимальный элемент без удаления:

```python
heap.peak()
```

Так как минимум находится в корне, операция выполняется за постоянное время.

## Сложность

### `add`

Новый элемент может подняться от нижнего уровня до корня.

Высота бинарной кучи:

```text
O(log n)
```

Поэтому:

```text
add — O(log n)
```

### `pop`

После переноса последнего элемента в корень он может опуститься до нижнего уровня.

Поэтому:

```text
pop — O(log n)
```

### `peak`

Минимальный элемент находится по индексу `0`:

```text
peak — O(1)
```

### `len`

Python хранит длину списка отдельно, поэтому:

```text
len — O(1)
```

### Память

Для хранения `n` элементов используется список размером `n`:

```text
O(n)
```

Дополнительная память для `add` и `pop`:

```text
O(1)
```

## Тесты

Тесты написаны с помощью `pytest`.

Запуск тестов кучи из корня проекта:

```bash
uv run pytest algorithms/data_structures/heap/test_heap.py -v
```

Или запуск всех тестов проекта:

```bash
uv run pytest -v
```

В тестах проверяются:

- добавление элементов;
- последовательное удаление элементов;
- уже отсортированные и обратно отсортированные данные;
- повторяющиеся значения;
- отрицательные числа;
- куча из одного элемента;
- попытка удалить элемент из пустой кучи;
- работа `peak`;
- изменение размера кучи;
- случайно сгенерированные данные.

Для общей проверки элементы последовательно извлекаются из кучи с помощью `pop` и сравниваются с результатом встроенной функции Python `sorted`.
