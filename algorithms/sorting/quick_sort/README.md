# Quick Sort

Моя реализация быстрой сортировки с разбиением массива на три части.

Сортировка работает **in-place** — исходный список изменяется напрямую, без создания нового отсортированного списка.

## Как работает Quick Sort

Общая идея быстрой сортировки довольно простая:

1. Выбираем опорный элемент — `pivot`.
2. Разделяем текущую часть массива на:
   - элементы меньше `pivot`;
   - элементы равные `pivot`;
   - элементы больше `pivot`.
3. Часть с элементами `< pivot` сортируем рекурсивно.
4. Часть с элементами `> pivot` тоже сортируем рекурсивно.

Элементы, равные `pivot`, повторно сортировать уже не нужно.

В моей реализации `pivot` — элемент из середины текущего диапазона:

```python
pivot = nums[(left + right) // 2]
```

## Структура реализации

Сортировка разделена на три функции:

```python
quick_sort()
_quick_sort()
_partition()
```

### `quick_sort`

Публичная функция, которую нужно вызывать для сортировки:

```python
nums = [5, 2, 8, 1, 3]

quick_sort(nums)

print(nums)
# [1, 2, 3, 5, 8]
```

Она запускает рекурсивную сортировку для всего списка.

### `_quick_sort`

Работает с конкретным диапазоном массива:

```python
nums[left:right + 1]
```

Если в диапазоне остался один элемент или диапазон пустой:

```python
if left >= right:
    return
```

сортировать больше нечего.

После `_partition` массив разделён на три области:

```text
< pivot | == pivot | > pivot
```

После этого рекурсивно сортируются только левая и правая части:

```python
_quick_sort(nums, left, equal - 1)
_quick_sort(nums, greater, right)
```

## Partition

Основная часть реализации — `_partition`.

Используется три указателя:

```python
equal
greater
current
```

Во время работы массив можно представить так через срезы Python:

```python
nums[left:equal]       # элементы < pivot
nums[equal:greater]    # элементы == pivot
nums[greater:current]  # элементы > pivot
nums[current:right+1]  # ещё не обработаны
```

## Сложность

### Время

В среднем:

```text
O(n log n)
```

`partition` проходит по текущему диапазону один раз, поэтому сам работает за:

```text
O(n)
```

После этого массив рекурсивно разбивается на меньшие части.

В худшем случае Quick Sort может работать за:

```text
O(n²)
```

Это происходит, если на каждом шаге получаются очень неравномерные разбиения.

### Память

Дополнительные массивы не создаются, поэтому сама перестановка элементов выполняется **in-place**.

Но используется рекурсия.

В среднем глубина рекурсии:

```text
O(log n)
```

В худшем случае:

```text
O(n)
```

## Тесты

Тесты написаны с помощью `pytest`.

Запуск всех тестов из корня проекта:

```bash
uv run pytest
```

Более подробный вывод:

```bash
uv run pytest -v
```

В тестах проверяются разные случаи:

- обычный неотсортированный список;
- уже отсортированный список;
- список в обратном порядке;
- повторяющиеся значения;
- отрицательные числа;
- список из одного элемента;
- пустой список.

Для проверки результата моя реализация сравнивается со встроенной функцией Python `sorted`.
