# Merge Sort

Моя реализация сортировки слиянием.

Алгоритм рекурсивно делит список на две части, сортирует каждую из них, а затем объединяет две отсортированные последовательности в одну.

Сортировка возвращает **новый отсортированный список**, исходный список не изменяется.

## Как работает Merge Sort

Общая идея:

1. Делим список пополам.
2. Рекурсивно сортируем левую половину.
3. Рекурсивно сортируем правую половину.
4. Объединяем две отсортированные половины с помощью `_merge`.

Деление продолжается, пока не останется список из одного элемента или пустой список:

```python
if len(nums) <= 1:
    return nums
```

## Merge

Функция `_merge` получает две уже отсортированные последовательности.

Используются два указателя:

```python
i
j
```

Они указывают на текущие элементы левого и правого списков.

На каждом шаге меньший элемент добавляется в результирующий список, после чего соответствующий указатель сдвигается.

Например:

```text
left  = [1, 4, 7]
right = [2, 3, 8]

result = [1, 2, 3, 4, 7, 8]
```

## Сложность

### Время

На каждом уровне рекурсии все элементы обрабатываются функцией `_merge`:

```text
O(n)
```

Количество уровней рекурсии:

```text
O(log n)
```

Итоговая временная сложность:

```text
O(n log n)
```

### Память

Для слияния создаются дополнительные списки, поэтому сортировка не является in-place.

Дополнительная память:

```text
O(n)
```

Также используется рекурсия глубиной:

```text
O(log n)
```

## Стабильность

Сортировка стабильная.

При одинаковых значениях сначала берётся элемент из левой части:

```python
left[i] <= right[j]
```

поэтому исходный порядок равных элементов сохраняется.

